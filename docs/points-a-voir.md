# Points à voir

> Propositions à trancher avant de continuer. Rien n'est décidé ici. Le texte vient de la page de vote et s'adresse à l'auteur du système.

## 1. Le nom, en sigle

Aucun des trois noms ne t'allait : tu voulais un sigle, comme SCP ou SHIELD. Voici quatre sigles qui se lisent comme un mot. J'ai cherché : aucun jeu de rôle ne porte ces noms. « Sous Scellés » est une gamme de jeux d'enquête (pas un jeu de rôle), et « Déni & Lucidité » un petit jeu sans rapport. Le nom ne change aucune règle.

**Exemples**

- À la table : « Ce soir, on joue à SCELLÉ. »
- Dans Foundry, en créant un monde : « Système de jeu : SCELLÉ ».
- Sur la fiche : « SCELLÉ · Agent Hugo, Traqueur niveau 1 ».
- Le MJ peut garder le sigle pour son organisation, ou en inventer une autre : les règles ne changent pas.

### Quel sigle pour le système ?

| Option | Comment ça marche | Vu dans |
| --- | --- | --- |
| S.C.E.L.L.É. (conseillé) | Service de Confinement des Entités, Lieux et Légendes Étranges. « Sous scellés » : enfermé, à ne pas ouvrir, comme les objets que garde SCP. *« L'objet part sous scellés à la base. »* |  |
| D.É.N.I. | Division d'Endiguement des Nuisances Inexpliquées. Le déni, c'est ce que l'organisation sert au public : rien ne s'est passé. *« Officiellement, une fuite de gaz. C'est le DÉNI qui a écrit le communiqué. »* |  |
| S.E.U.I.L. | Service d'Étude et d'Urgence des Incidents Liminaux. Rappelle la barre de 100 à dépasser. *« Le SEUIL envoie une équipe à la maison hantée. »* |  |
| F.Ê.L.U.R.E.S. | Force d'Élimination et de Lutte contre les Urgences, Résurgences et Entités Surnaturelles. Garde l'idée des fêlures, mais le sigle est long. *« Agent des FÊLURES, montrez votre badge. »* |  |
| Un sigle à toi | Écris-le dans la note, avec ce que veulent dire les lettres si tu l'as. Je vérifierai qu'aucun jeu connu ne le porte. *Le sigle s'affichera partout : Foundry, fiche, chat et dépôt.* |  |

## 2. La langue du système

Dernier choix avant le code : dans quelle langue écrire les textes du système (fiche, fenêtres, messages du chat). Les règles restent en français.

**Exemples**

- Ta table joue en français : la fiche dit « Esquive », la fenêtre dit « Difficulté ».
- Un ami anglophone installe le système : avec un fichier anglais, il lit « Dodge » et « Difficulty ».
- Pour publier sur le site de Foundry, l'anglais aide, mais rien ne l'oblige.
- Changer un mot (par exemple « Esquive ») se fait dans le fichier de langue, sans toucher au code.

### Quelle langue pour la fiche et les fenêtres ?

| Option | Comment ça marche | Vu dans |
| --- | --- | --- |
| Le français d'abord, l'anglais plus tard (conseillé) | Tous les textes sont rangés dans un fichier de langue français. On pourra ajouter l'anglais plus tard sans toucher au code. *Dans six mois, un fichier anglais suffit pour que ton ami joue.* |  |
| Français et anglais dès le début | Chaque texte est écrit deux fois. On peut partager le système tout de suite, mais chaque changement coûte double. *Tu renommes « Esquive » : il faut aussi choisir le mot anglais.* |  |
| Le français seulement | Pas d'anglais prévu. Les textes restent quand même dans un fichier de langue, comme le veut Foundry. *Ton ami anglophone devra faire sa traduction lui-même.* |  |
