# Catalogue d'idées

Petites mécaniques relevées dans d'autres jeux (JdR, jeux vidéo, jeux de plateau), à trier. On n'en copie aucune telle quelle : on garde ce qui plaît et on construit nos propres règles.

La colonne « Foundry » estime le travail de code. Les idées marquées * contiennent un détail cité de mémoire, non vérifié.
