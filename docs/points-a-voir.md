# Points à voir

> Propositions à trancher avant de continuer. Rien n'est décidé ici. Le texte vient de la page de vote et s'adresse à l'auteur du système.

## 1. Le nom : nouvelle fournée

Toujours pas le bon nom, alors voici neuf sigles plus courts, en anglais comme SCP et SHIELD, ou en français. Note-les un par un : « Oui » si tu aimes, « À changer » si c'est presque ça (dis quoi), « Non » sinon. Même sans coup de cœur, tes votes me diront quel style chercher. J'ai cherché HUSH, GRAVE et GLAS : aucun jeu de rôle ne porte ces titres (un petit jeu solo s'appelle « Hush »). Je vérifierai les autres si tu les aimes.

**Exemples**

- À la table : « Ce soir, on joue à HUSH. »
- Dans le chat de Foundry : « GLAS · Biologie, jet dur : réussi ».
- Sur la fiche : « CENT · Agent Hugo, Traqueur niveau 1 ».
- Mes deux préférés : HUSH (la discrétion, au cœur des missions) et GLAS (la cloche qu'on sonne pour les morts).

### Quel genre de sigle te parle le plus ?

| Option | Comment ça marche | Vu dans |
| --- | --- | --- |
| Un mot anglais, comme SHIELD | Court, se dit facilement, sonne « agence secrète ». *HUSH, GRAVE, WARD, DUSK, ASH.* |  |
| Un mot français | Plus proche de ta table, qui joue en français. *GLAS, NOIR, ARCHE, CENT.* |  |
| Des lettres qu'on épelle, comme SCP | Trois ou quatre lettres qui ne forment pas un mot. Dis-moi dans la note, je chercherai dans ce style. *« Le S-C-P a envoyé une équipe. »* |  |
| Peu importe, c'est le sens qui compte | Je chercherai d'abord un sigle qui parle de discrétion, de mort ou d'enfermement. *HUSH (le silence), GLAS (la mort), ARCHE (l'enfermement).* |  |

### Les neuf sigles

- H.U.S.H. : Hidden Unit for Supernatural Hazards. « Hush » veut dire « chut » : l'unité qui fait taire. *« Officiellement, il ne s'est rien passé. HUSH s'en occupe. »*
- G.R.A.V.E. : Global Response Agency for Violent Entities. « Grave », c'est la tombe. *« Une équipe de GRAVE est déjà sur place. »*
- W.A.R.D. : Watch Against Rifts and Demons. Un « ward », c'est une protection, un garde. *« Les agents de WARD bouclent le quartier. »*
- D.U.S.K. : Division for Unnatural Sightings and Kills. « Dusk », c'est le crépuscule. *« DUSK intervient à la tombée de la nuit. »*
- A.S.H. : Anomalies, Spirits and Hauntings. « Ash », c'est la cendre ; trois lettres, comme SCP. *« Dossier transmis à ASH. »*
- G.L.A.S. : Groupe de Lutte contre les Apparitions Surnaturelles. On sonne le glas pour les morts. *« Quand le GLAS arrive, c'est que quelqu'un va mourir. »*
- N.O.I.R. : Neutralisation des Occurrences Inexpliquées et Rituelles. Le noir, et le roman noir. *« Une affaire classée NOIR. »*
- A.R.C.H.E. : Agence de Recherche et de Confinement des Hantises et Entités. L'arche qui enferme et protège. *« L'objet part à l'ARCHE, sous clé. »*
- C.E.N.T. : Cellule d'Enquête et de Neutralisation des Ténèbres. Cent, c'est la barre du d100 à dépasser. *« Il faut faire plus que CENT. »*

## 2. En attendant le nom

La langue est choisie (le français d'abord). Seul le nom manque pour commencer le code. On peut commencer quand même avec le nom provisoire, et le remplacer quand tu l'auras trouvé.

**Exemples**

- Dans quelques jours, tu crées Hugo dans un monde de test et tu lances ses premiers jets.
- Le jour où tu choisis le nom, je le remplace partout ; tu recrées le monde de test.
- Aucun vrai monde n'est créé avant le nom : rien à réparer ensuite.
- Si tu préfères attendre, on continue les fournées de noms, et le code commence après.

### On commence le code avant d'avoir le nom ?

| Option | Comment ça marche | Vu dans |

| Oui, avec le nom provisoire (conseillé) | Le système s'appelle « systeme-jdr » le temps des tests. Je le remplace partout le jour où tu choisis le nom. *Tu testes la fiche de Hugo pendant qu'on cherche encore le nom.* |  |
| Non, attendre le nom | Rien n'est codé tant que le nom n'est pas trouvé. *On choisit d'abord le nom, puis le code commence.* |  |
