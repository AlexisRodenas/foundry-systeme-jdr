# Conception du système

Ce document sépare ce qui est **décidé**, ce qui **plaît** et ce qui reste **ouvert**.

## Décidé

| Sujet | Décision |
| --- | --- |
| Nom | Provisoire (`systeme-jdr`). À fixer avant de créer un vrai monde Foundry avec ce système. |
| Ambiance | Dark fantasy / moderne / horreur |
| Univers | Un seul, qui mélange les trois |
| Cadre | Une organisation secrète qui règle le paranormal sans se faire remarquer |
| Personnages | Trois types jouables ensemble : gens ordinaires dépassés, chasseurs qui savent, êtres touchés par le surnaturel |
| Complexité | Moyenne : quelques sous-systèmes profonds, le reste simple |
| Sensation des dés | Suspense, tout peut arriver |
| Style de règles | Du concret (barres, stats, jets). Les mécaniques narratives ont presque toutes été écartées. |
| Magie par cercles | Pas au cœur du système. Ajout possible plus tard. |
| Plateforme | Foundry VTT v14, dépôt public |
| Méthode | On trie de petites idées venues d'autres jeux, puis on construit avec celles qui plaisent : voir [idees.md](idees.md) |

## Ce qui plaît

- **Santé mentale** : une stat qui fonctionne comme une deuxième barre de vie.
- **Craquer ou se révéler** : à bout, le plus souvent on craque, parfois on devient héroïque.
- **d20 avec des d6 d'avantage ou de désavantage.**
- **Forcer un jet raté**, avec une conséquence annoncée.
- **Viser un membre**, sur les monstres comme sur les personnages.
- **La pression monte** : une jauge de discrétion, parce que les missions doivent rester secrètes.

## À retravailler

- **Faiblesse des monstres** : plutôt liée à un effet légendaire.
- **Quartier général** : un lieu où le groupe revient entre les missions.
- **Séquelles étranges** : plutôt des effets venant des entités elles-mêmes.
- **Chance limitée, stress qui aide, indice vital toujours trouvé** : avis partagé.
