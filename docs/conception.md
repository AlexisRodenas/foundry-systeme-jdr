# Conception du système

Ce document sépare ce qui est **décidé** de ce qui est **proposé** ou **ouvert**. Rien de « proposé » n'est acquis.

## Décidé

| Sujet | Décision |
| --- | --- |
| Nom | Provisoire (`systeme-jdr`). À fixer avant de créer un vrai monde Foundry avec ce système. |
| Ambiance | Dark fantasy / moderne / horreur |
| Complexité | Moyenne : quelques sous-systèmes profonds, le reste simple |
| Sensation des dés | Suspense, tout peut arriver |
| Magie par cercles | Pas au cœur du système. Ajout possible plus tard. |
| Plateforme | Foundry VTT v14, dépôt public |

## Ouvert

1. Ambiance : un seul univers qui mélange les trois (monde moderne où rôde une dark fantasy horrifique), ou trois cadres séparés sur le même moteur ?
2. Mécanique de dés
3. Ce qui rend le système unique
4. Caractéristiques et compétences
5. Combat, blessures, mort
6. Progression des personnages
7. Nom définitif et licence

## Proposé : le Dé d'Ombre

**Jet de base :** 1d20 + bonus, à comparer à une difficulté.

**Dé d'Ombre :** *avant* de lancer, le joueur peut ajouter son dé d'Ombre au jet. Son résultat s'ajoute au total. Mais s'il affiche **4 ou plus**, l'action a un **prix** (réussie ou non) : blessure, peur, trahison du décor, quelque chose qui remarque le personnage.

Plus le dé aide, plus il coûte. C'est toujours le joueur qui choisit de prendre le risque.

**Il grandit :** d4 → d6 → d8 → d10 → d12 à mesure que le personnage s'enfonce. Un personnage corrompu est puissant et dangereux, d'abord pour lui-même. Au-delà du d12, il est perdu.

Exemple avec un bonus de +3 contre une difficulté de 15 :

| Dé ajouté | Chances de réussir | Risque de payer un prix |
| --- | --- | --- |
| aucun | 45 % | 0 % |
| d4 | 57,5 % | 25 % |
| d6 | 62,5 % | 50 % |
| d8 | 67,5 % | 62,5 % |
| d10 | 72,5 % | 70 % |
| d12 | 77,1 % | 75 % |
